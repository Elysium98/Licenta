# BooksApp

## Overview
BooksApp is a **web platform for managing teaching materials between students**. The application allows users to:  
- View books available for sale, along with their details
- Register and login to add, edit and sell their own books
- Edit their account details
- Contact the administration via a contact form, which sends messages directly to the application's email

### Architecture & Technology
- **Frontend**: Angular, Angular Material
- **Backend**: ASP.NET Core API using **n-layer architecture**,  Entity Framework Core, SQL, Identity
- **Pattern**: MVC  
- **Security**: HTTPS with SSL certificate, Bearer authentication with JWT and Identity  
- **Testing**: Requests tested using Postman
